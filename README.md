## 📌 Overview

Smart Hire Engine is a web-based application designed to automate resume screening and candidate ranking using **Natural Language Processing (NLP)**. It compares candidate resumes with job descriptions, calculates similarity scores, and ranks candidates based on their relevance to job requirements.

## ✨ Key Features

- 🔐 User authentication.
- 📄 Resume upload and text extraction.
- 📋 Job description selection.
- 🧠 NLP-based resume evaluation.
- 📊 TF-IDF and cosine similarity matching.
- 🏆 Candidate scoring and ranking.
- 🎯 Top candidate shortlisting.
- ⬇️ Resume download functionality.

## 🛠️ Technology Stack

| Component | Technology |
|---|---|
| 💻 Programming Language | Python |
| ⚙️ Backend | Flask |

| ☁️ Deployment | Render |

## ⚙️ Installation and Execution

**1. Clone the repository**

```bash
git clone https://github.com/tejugowda-03/Smart-Hire-Engine-Resume-Evaluation-and-Ranking-System.git
```

**2. Install dependencies**

```bash
pip install -r requirements.txt
```

**3. Configure environment variables**

Set the required `SECRET_KEY` and `DATABASE_URL`.

**4. Run the application**

```bash
python run.py
```

**5. Access the application**

🌐 http://127.0.0.1:8000/
